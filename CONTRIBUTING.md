# Contributing to BuddyBot

We welcome contributions from the community! If you would like to contribute to BuddyBot, please follow these guidelines.

## How to Contribute

1.  Fork the repository.
2.  Create a new branch for your feature or bug fix.
3.  Make your changes.
4.  Write tests for your changes.
5.  Run the tests to make sure they pass.
6.  Submit a pull request.

## Code Style

We use the [PEP 8](https://www.python.org/dev/peps/pep-0008/) style guide for Python code. Please make sure your code adheres to this style guide.

## Issue Tracking

We use GitHub Issues to track bugs and feature requests. If you find a bug or have a feature request, please open an issue on our [GitHub repository](https://github.com/your-username/buddybot/issues).

## Pull Requests

We welcome pull requests! If you would like to submit a pull request, please make sure it meets the following criteria:

-   The pull request should be well-documented.
-   The pull request should include tests.
-   The pull request should be based on the `main` branch.
